# 🌐 Portfolio - Pham Gia Luong (Vanilla JS Version)

Welcome to my personal portfolio website!  
This branch showcases a lightweight, high-performance version of my portfolio built entirely from scratch without any heavy frontend frameworks. It highlights my strong foundational skills in UI design, DOM manipulation, and responsive web development.

## 🚀 Tech Stack

- **Frontend Core**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Architecture**: Data-Driven Rendering (Projects are dynamically loaded from `data.js`)
- **Typography & Icons**: Google Fonts (Outfit, Philosopher), FontAwesome 6
- **Deployment**: GitHub Pages

## 🛠️ Key Features

- **Zero Dependencies**: Fast load times with no external JavaScript libraries or build tools required.
- **Dynamic Content Generation**: The Projects section is dynamically rendered using JavaScript array mapping, making it extremely easy to scale and maintain.
- **Interactive UI/UX**: 
  - Custom Parallax hover effects on the Hero section shapes.
  - Intersection Observer API for smooth scroll animations (Slide-up & Fade-in).
  - Fully responsive navigation bar with a mobile hamburger menu.
- **Project Modal Viewer**: A custom-built modal system that includes an iframe to preview technical PDF reports directly on the page.

## 🔧 Local Setup

Since this is a Vanilla JS project, no package manager (npm/yarn) or build process is required!

1. Clone the repository:
   ```bash
   git clone [https://github.com/PhamGiaLuong/portfolio.git](https://github.com/PhamGiaLuong/portfolio.git)
   cd portfolio
    ```

2. Simply open `index.html` in your web browser.
3. *Recommended:* Use an extension like **Live Server** in VS Code for a better development experience with hot reloading.

## 🌍 Deployment

This site is deployed directly on **GitHub Pages**.
Whenever code is pushed to the main branch, GitHub Pages automatically serves the static files without any build steps (`npm run build` is not needed here).
